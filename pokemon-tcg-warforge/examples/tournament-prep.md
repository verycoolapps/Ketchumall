# 🏆 TOURNAMENT PREP — EXAMPLE

> Worked example: Preparing for a Regional championship.

---

## USER REQUEST
> "I have a Regional this Saturday. I'm playing Dragapult ex. Give me a complete tournament preparation plan."

---

## WARFORGE RESPONSE

### PRE-TOURNAMENT PROTOCOL

```
═══════════════════════════════════════════════════════════
TOURNAMENT PREPARATION: Dragapult ex — Regional
═══════════════════════════════════════════════════════════
```

### 1. FORMAT CONFIRMATION

- [x] **Format:** Standard
- [x] **Event:** Regional championship
- [x] **Structure:** Best-of-three (Bo3)
- [x] **Time limit:** 50 minutes per round (standard)
- [x] **Decklist:** Submitted at registration
- [x] **Sideboard:** Allowed between games (if applicable)

### 2. DECK FINALIZATION

**Main deck:** Dragapult ex (60 cards)
**Sideboard considerations:**
- Game 1: Main deck only (learn their deck)
- Games 2-3: Adjust for their archetype

**Tech cards to consider:**
- Boss's Orders (essential — already in deck)
- Crushing Hammer (vs energy-dependent decks)
- Judge/Xerosicclaw (vs combo/control)
- Extra draw supporters (vs disruption)

**Backup options:**
- If meta shifts to aggro: Consider Grimmsnarl
- If meta shifts to control: Consider Lucario ex
- If unsure: Stick with Dragapult (proven)

### 3. MENTAL PREPARATION

**Know your deck cold:**
- [x] Every card's function
- [x] Evolution line (Dreepy → Drakloak → Dragapult ex)
- [x] Energy requirements (2 psychic energy for Dragapult)
- [x] Key combos (Ultra Ball + evolution, Boss + KO)

**Know your game plan:**
- [x] Turn 1: Set up Dreepy/Drakloak, attach energy
- [x] Turn 2: Evolve to Dragapult, start attacking
- [x] Turn 3+: Close game with Dragapult damage

**Know your bad matchups:**
- [x] vs Grimmsnarl: Disruption hurts our consistency
- [x] vs Control: They stall, we need to race
- [x] vs Combo: They assemble pieces, we need to disrupt

**Know your mulligan strategy:**
- [x] Keep: Dreepy + energy + any trainer
- [x] Mulligan: No Basic, no energy, too many trainers
- [x] vs Aggro: Keep T1 attacker hands
- [x] vs Control: Keep consistency hands

### 4. MATCHUP PREPARATION

**vs Dragapult ex (mirror):**
- [x] Skill matchup — better player wins
- [x] Focus on tempo, don't waste resources
- [x] Boss timing is critical
- [x] Don't overextend into their Boss

**vs Grimmsnarl (control):**
- [x] They disrupt our hand/items
- [x] We need to set up fast before they stabilize
- [x] Add extra draw supporters if possible
- [x] Boss their key attackers when they try to set up

**vs Charizard ex (aggro):**
- [x] Race matchup — who sets up first
- [x] They hit hard, we hit harder
- [x] Trade efficiently — don't let them take easy prizes
- [x] Boss their Charizard when it's biggest threat

**vs Gardevoir ex (midrange):**
- [x] They spread damage, we need to KO efficiently
- [x] Boss their Gardevoir when it's setting up
- [x] Don't let them stabilize their engine

**vs Tech/misc:**
- [x] Adapt based on their game plan
- [x] Don't assume — observe their plays
- [x] Tech for their specific weaknesses

### 5. TOURNAMENT DAY PROTOCOL

**Morning:**
- [ ] Good sleep (7-8 hours)
- [ ] Healthy breakfast (protein + carbs)
- [ ] Review decklist and game plan (15 min)
- [ ] Check deck legality one more time
- [ ] Pack: sleeves, markers, dice, notes, water, snacks

**At venue:**
- [ ] Arrive early (30 min before start)
- [ ] Find your table/area
- [ ] Warm up with practice games (if time)
- [ ] Mental prep: visualize success, focus on process

**Between rounds:**
- [ ] Hydrate (water, not just coffee)
- [ ] Light snack (fruit, nuts, not heavy food)
- [ ] Quick review of last match (2 min)
- [ ] Prepare mentally for next opponent
- [ ] Don't carry frustration forward

**During matches:**
- [ ] Track time (50 min rounds)
- [ ] Don't stall — make decisions
- [ ] If behind on time, simplify play
- [ ] If ahead on time, can afford calculation
- [ ] Stay focused — tunnel vision kills

### 6. MATCH DAY STRATEGY

**Swiss rounds:**
- Game 1: Learn their deck, don't reveal sideboard
- Games 2-3: Adjust sideboard for their archetype
- Track their key cards, patterns, weaknesses
- Don't overthink — play your game

**Top cut:**
- Higher stakes, more pressure
- Prepare for likely matchups (Dragapult, Grimmsnarl)
- Focus on mental game — stay calm
- Trust your preparation

### 7. PERFORMANCE REVIEW

**After each match:**
- [ ] Did I execute my game plan?
- [ ] Did I misplay any key turns?
- [ ] Did I face bad variance or good play?
- [ ] What would I do differently?

**After tournament:**
- [ ] Overall record: W-L
- [ ] Matchup breakdown: which decks did I beat/lose to?
- [ ] Key moments: turning points in matches
- [ ] Deck performance: did the deck do what I expected?
- [ ] Play performance: what can I improve?

**Iteration:**
- [ ] Adjust deck based on what you faced
- [ ] Adjust play style based on what worked
- [ ] Identify patterns in losses
- [ ] Targeted practice for weak areas

### 8. MENTAL GAME

**Tilt prevention:**
- Accept variance — Pokémon TCG has luck
- Don't chase losses — each game is independent
- Focus on decisions, not results
- Take breaks between rounds
- Stay hydrated, eat, breathe

**Pressure management:**
- Visualize success before matches
- Focus on process, not outcome
- Remember: everyone feels pressure
- Use routine: same warmup, same breathing, same prep

**Recovery:**
- Loss happens — analyze it, learn from it, move on
- Don't dwell on what you can't change
- Focus on what you CAN control: your decisions, your preparation, your attitude

### 9. CONTINGENCY PLANS

**If you lose early:**
- Don't panic — Swiss is long
- Analyze what went wrong
- Adjust for next round
- Stay positive — one loss doesn't define tournament

**If you win early:**
- Don't get overconfident
- Stay focused — every game matters
- Prepare for stronger opponents
- Keep same routine — don't change what works

**If you face bad matchup:**
- Accept it might be a loss
- Play your best — maybe they misplay
- Learn from it for future
- Don't tilt — one bad matchup doesn't end tournament

**If you feel tilt:**
- Take a break (walk, breathe, hydrate)
- Reset mentally — next game is fresh
- Focus on process, not results
- Remember: everyone feels this way

### 10. FINAL CHECKLIST

**Day before:**
- [ ] Deck finalized and tested
- [ ] Matchup notes reviewed
- [ ] Mental preparation done
- [ ] Sleep schedule normal
- [ ] Confidence: "I've prepared, I'll do my best"

**Tournament day:**
- [ ] Arrived early
- [ ] Deck checked and legal
- [ ] Mental state: calm, focused, ready
- [ ] Ready to play your best

**During tournament:**
- [ ] Playing with confidence
- [ ] Making good decisions
- [ ] Adapting to opponents
- [ ] Enjoying the experience

### EXPECTED OUTCOMES

**Realistic goals:**
- Swiss: 7-3 to 9-3 (make top cut)
- Top cut: Competitive for Top 8/16
- Stretch goal: Top 8 finish

**Unrealistic goals:**
- "Win the whole thing" — possible but unlikely
- "Go undefeated" — variance happens
- "No mistakes" — everyone makes mistakes

**Focus on:**
- Playing well
- Learning from matches
- Enjoying the experience
- Improving for next time

### KEY TAKEAWAYS

1. **Preparation is key** — know your deck, know your matchups
2. **Mental game matters** — stay calm, focused, confident
3. **Adapt to opponents** — don't force same line every game
4. **Learn from every match** — win or lose, there's always something to improve
5. **Enjoy the experience** — it's supposed to be fun

This preparation plan gives you the best chance to succeed. Now go play your best!
