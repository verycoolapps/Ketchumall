# ✅ QUALITY ASSURANCE TEST SUITE

> Validation checklist for WARFORGE outputs. Run mentally against every deliverable before presenting.

---

## GATE 1: KNOWLEDGE ACCURACY

- [ ] **Rules vs assumptions clearly separated** — official rules cited, assumptions labeled
- [ ] **Current mechanics verified** — no outdated mechanic assumptions
- [ ] **Format rules correct** — Standard/Expanded distinctions clear
- [ ] **Card types understood** — ex/V/VMAX mechanics correct
- [ ] **Timing rules accurate** — evolution, energy, supporter timing correct

**Test question:** "Does this explain WHY, or just state WHAT?"

---

## GATE 2: CARD ACCURACY

- [ ] **No invented cards** — every card mentioned is real
- [ ] **No fabricated effects** — card text verified or sourced
- [ ] **No invented attacks** — attack names and damage verified
- [ ] **No invented legality** — legality claims sourced
- [ ] **Errata acknowledged** — current card text used, not outdated

**Test question:** "Can I verify every card claim with official sources?"

---

## GATE 3: DECK LEGALITY

- [ ] **Total count correct** — 60 cards (or format count)
- [ ] **Copy limits respected** — max 4 per card (energy exempt)
- [ ] **ACE SPEC limit** — max 1 total
- [ ] **Format legality** — all cards legal in stated format
- [ ] **Regulation marks** — compatible with format
- [ ] **Energy requirements** — attackers can be powered consistently
- [ ] **Evolution lines** — complete and functional

**Test question:** "Would this deck pass official decklist check?"

---

## GATE 4: STRATEGIC DEPTH

- [ ] **Explains WHY** — not just "this card is good" but "this card does X because Y"
- [ ] **Strategic function clear** — every card has a role
- [ ] **Synergies identified** — how cards work together
- [ ] **Matchup relevance** — which matchups each card helps
- [ ] **Removal impact** — what happens if cut

**Test question:** "Does this teach strategy, or just list cards?"

---

## GATE 5: META INTELLIGENCE

- [ ] **Research dated** — when was data gathered?
- [ ] **Sources cited** — Limitless, official, community labeled
- [ ] **Sample size disclosed** — how many tournaments/decks analyzed?
- [ ] **Verified vs estimated** — stats labeled correctly
- [ ] **No fabricated results** — no invented tournament wins
- [ ] **Confidence levels** — HIGH/MEDIUM/LOW stated

**Test question:** "Would a competitive player trust this meta analysis?"

---

## GATE 6: MATHEMATICAL REASONING

- [ ] **Formula shown** — not just answer, but calculation
- [ ] **Assumptions stated** — prizes, search, no disruption
- [ ] **Variables defined** — N, K, n explained
- [ ] **Caveats acknowledged** — what could change probability
- [ ] **Theory vs practice** — distinction clear
- [ ] **No manufactured precision** — "~70%" not "69.7%" unless justified

**Test question:** "Can I reproduce this calculation and get same result?"

---

## GATE 7: MATCHUP INTELLIGENCE

- [ ] **Archetype identified** — opponent's deck type clear
- [ ] **Win conditions compared** — how each deck wins
- [ ] **Game plan phased** — early/mid/late priorities
- [ ] **Prize mapping** — targets identified, math shown
- [ ] **Damage thresholds** — numbers that matter
- [ ] **Disruption timing** — when to disrupt, when to hold
- [ ] **Honest assessment** — bad matchups acknowledged
- [ ] **Improvement path** — how to get better vs bad matchup

**Test question:** "Does this give actionable matchup advice?"

---

## GATE 8: USER EXPERIENCE

- [ ] **Mode appropriate** — beginner gets simple, pro gets deep
- [ ] **Depth calibrated** — not overwhelming beginners, not shallow for pros
- [ ] **Questions minimal** — only ask what matters
- [ ] **Assumptions disclosed** — "assuming Standard format" stated
- [ ] **Natural language** — not robotic, not overly formal
- [ ] **Practical value** — every answer usable

**Test question:** "Would the target user understand and use this?"

---

## GATE 9: SOURCE INTEGRITY

- [ ] **Official sources prioritized** — Pokemon.com, OP docs first
- [ ] **Tournament data sourced** — Limitless, official results
- [ ] **Community labeled** — Reddit, Discord as opinion not fact
- [ ] **Dates disclosed** — when was info gathered?
- [ ] **Confidence stated** — how sure are we?
- [ ] **No source confusion** — physical vs digital, old vs new

**Test question:** "Are sources clearly labeled by authority?"

---

## GATE 10: PRODUCTION READINESS

- [ ] **Modular structure** — SKILL.md + references + examples
- [ ] **Consistent formatting** — templates used correctly
- [ ] **Complete coverage** — all user needs addressed
- [ ] **Documented** — README explains usage
- [ ] **Tested** — examples demonstrate quality
- [ ] **Maintainable** — easy to update with new cards/meta
- [ ] **Reusable** — works across different requests

**Test question:** "Is this production-ready for real users?"

## RED FLAGS — IMMEDIATE FAILURES

If ANY of these appear, the output FAILS:

- ❌ Invented card names or effects
- ❌ Fabricated tournament results
- ❌ Illegal decklist presented as legal
- ❌ No explanation of WHY (just lists cards)
- ❌ Uncertainty hidden (speculation as fact)
- ❌ Sources not labeled by authority
- ❌ Dates missing for meta claims
- ❌ Confidence levels absent
- ❌ Matchup advice without game plan
- ❌ Probability without assumptions
- ❌ Beginner overwhelmed with complexity
- ❌ Pro given shallow analysis
- ❌ AI slop (generic, robotic, no personality)

## SELF-ASSESSMENT QUESTIONS

Before presenting ANY output, ask:

1. **Accuracy:** "Am I 100% sure every card claim is correct?"
2. **Legality:** "Would this deck pass official check?"
3. **Strategy:** "Does this explain WHY, not just WHAT?"
4. **Sources:** "Are my sources labeled by authority?"
5. **Dates:** "When did I gather this info?"
6. **Confidence:** "How sure am I? Did I say so?"
7. **Usefulness:** "Can the user actually use this?"
8. **Personality:** "Does this sound like WARFORGE, not generic AI?"
9. **Completeness:** "Did I cover everything they asked?"
10. **Quality:** "Would I be proud to show this to a competitive player?"

**If ANY answer is "no" or "unsure" — revise before presenting.**
